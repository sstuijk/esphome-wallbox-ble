# ESPHome Wallbox Pulsar Plus BLE Component

Local Bluetooth Low Energy (BLE) component for ESPHome to control and monitor a **Wallbox Pulsar Plus EV Charger** directly without relying on the cloud.

## Features
- **Status Monitoring:** Numeric state and human-readable text status.
- **Energy Monitoring:** Real-time charging energy consumption in kWh.
- **Lock Control:** Lock / Unlock charger sessions locally.
- **Charging Current Control:** Slider to set max charging current from 6A to 25A.
